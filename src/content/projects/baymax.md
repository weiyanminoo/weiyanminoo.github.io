- Built it individually as part of NUS module CS2103T, growing it a feature at a time from a command-line chatbot into a JavaFX desktop app.
- Tracks three kinds of task (to-dos, deadlines and dated events) with commands to mark, find, delete and undo.
- Packaged as a single runnable JAR with Gradle, with JUnit 5 tests, assertions and a user guide published on GitHub Pages.
