- Full stack development of a mobile application using React Native, TypeScript and a Firebase-powered backend, with on-device OCR and AI parsing to extract details from prescription slips and schedule reminders, reducing medical non-adherence.
- Built a Java Spring Boot microservice, complementing Firebase, to verify Firebase ID tokens and schedule dose reminders.
- Piloting a Spring Boot API for reports and integrations, exposing adherence and analytics endpoints.
- Implemented a CI/CD pipeline with GitHub Actions to automate linting, unit tests and EAS builds.
- Defined product strategy and validated the solution through user interviews, rapid Figma prototyping and beta testing.
