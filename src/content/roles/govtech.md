- Developed and maintained frontend features for the Workpal mobile app using React Native, JavaScript and Redux, for around 100,000 public service officers in Singapore.
- Built responsive UI components using Flexbox layouts, the Dimensions API and custom scaling utilities, keeping the experience consistent across Android and iOS and across device sizes.
- Created native bridges in Kotlin and Swift using the React Native bridge API, exposing deep linking handlers, app shortcuts and secure storage access to JavaScript.
- Migrated legacy native screens by embedding ReactRootView within existing Android Activities and iOS ViewControllers, letting React Native modules run inside native navigation stacks without rewriting the whole app.
- Diagnosed and resolved platform-specific layout inconsistencies, lifecycle bugs and navigation edge cases.
